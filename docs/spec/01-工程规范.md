## 3. 编码规范

- **错误**：跨层一律 `fmt.Errorf("...: %w", err)` 包装；跨模块错误用 00 §6.7 哨兵错误，判定用 `errors.Is`；新增跨模块错误先在 00 登记。
- **context**：一律第一个参数；请求路径禁止出现 `context.Background()`（后台任务除外，且须带取消与超时）。
- **并发**：请求路径禁止裸 `go func`；后台任务用 errgroup；每个 channel 必须有明确的 close 责任人。
- **时间/金额**：`time.Duration` 不以 int 毫秒穿越 API 边界；金额一律微元 int64（00 §7.4）。
- **TODO**：`TODO(xx.y): 说明`——必须指向文档编号，禁止无主 TODO；跨批移交项同步登记 02 台账并在注释引用编号（如 `台账#3`）。

### 3.1 GORM 使用细则（源自 11.1 实现反馈）

- 禁用 AutoMigrate（§1 基线）；schema 一律由迁移文件管理，GORM 仅作模型映射与查询层。
- **Create 显式置值**：GORM 会把结构体零值（如 `""`）写入并覆盖 DDL 默认——依赖 DDL 默认值的列必须在结构体显式赋值。案例：seed 漏置 `health_status` 写入空串（台账 #1）。
- **勿复用带主键的 struct 作查询目标**：`First(&c)` 复用已含主键的 struct 会附加 `WHERE id=?` 条件导致查不到行——每次查询用新变量。案例：`TestSeed_HealsEmptyHealthStatus` 首版失败。
- **保留字**：MySQL 8+ 保留字（如 `GROUPS`）在 GORM 与迁移 DDL 中由反引号保护，**手写原生 SQL 时需自查**。
- **JSON 列写入**：空串会被 MySQL 拒绝（Error 3140，非法 JSON 文档）——空值以 `*string`/NULL 写入；且 JSON 列会规范化文本（`"[3,4]"` → `"[3, 4]"`），消费方须按**解析后的值**判定，不得比字符串（源自 11.2，台账 #7）。
- 迁移专用连接的 DSN 需 `multiStatements=true`（迁移文件含多条 DDL，11.1 §9.3）。

## 4. 日志规范

- 级别：`Error`（影响请求结果）/ `Warn`（可自愈异常、软阈值）/ `Info`（请求完成摘要）/ `Debug`（分片级，默认关闭）。
- 每请求完成打一行摘要：`msg="request_done"` + 00 §8.3 字段全集。
- **禁止**打印 API Key 明文与渠道密钥（只打前 8 位前缀）。
- request_id 缺失的请求路径日志视为 bug。
- **时间键为 `ts`**（00 §8.3 契约）：slog 默认键 `time` 须经 `ReplaceAttr` 改写；测试中捕获日志的 logger 必须镜像同一 `ReplaceAttr`，保证断言的就是生产键名（源自 10.2 评审阻断项①）。

## 5. 测试策略

- 单测：表驱动；Redis 依赖用 miniredis；HTTP 用 httptest。
- 并发测试：**16.3 熔断窗口、17.2 配额结算必须有并发用例**；凡含并发的测试一律以 `go test -race` 通过为验收条件。
- **断言质量（评审必查）**：验收用例必须有行为级断言——只 `require.NoError` / 只跑通不算覆盖。反例：缓存命中测试不断言"第二次调用不产生 SQL"（11.2 §5 用例②），就等于没测。
- **机制性证据**：幂等/零写类断言须给出机制证据（如 `updated_at` 不变、AES-GCM 密文字节不变——nonce 随机则重加密必变），不能用"恰好行数没变"凑数（源自 11.1 §9.4）。
- **时序断言用区间**：超时/延迟类断言用区间（配置 50ms + 上限 100ms）而非精确值，防 CI 慢机抖动（源自 15.2 原则，通用化）。
- e2e：`test/e2e/` 沉淀每批检查点脚本（bash + curl），**只增不改**——历史脚本即回归资产。
- 覆盖率：不设数字红线；硬性要求是每个 L2 验收标准中列出的用例全部存在且绿。

**B3 验收补充候选**：当多个测试包共用会重建的 gaigate_test 时，限定／全仓 SQL 回归必须以 `go test -p 1 -count=1 ... -v` 串行执行，各包内的重建用例不 t.Parallel；不得同时运行第二个会重建该库的测试或进程 fixture。普通无 SQL 的单元／并发机制测试不受此串行限制。-race 也不能并行启动另一个 SQL 回归。专用进程 fixture 只能显式把 GAIGATE_TEST_MYSQL_* 转为子进程所需的 GAIGATE_MYSQL_*，数据库强制 gaigate_test；不覆盖父进程或连接开发业务库。此项补充防止 B3 新增 access／命令包与既有 store 包在同一测试库相互 DROP。

## 6. Git 与交付约定

- 分支：`l2/<编号>`（如 `l2/16.3`）；一个 L2 一个分支一个 PR。
- Commit：`<type>(<L2编号>): 描述`，如 `feat(16.3): 滑动窗口熔断 Lua 脚本`。
- **合并前置条件**（全部满足才合并）：① `golangci-lint run` 与 `go test ./...` 绿；② 验收脚本跑通；③ §9 验收记录已回填（00 §2.2 v0.4 惯例）；④ 独立评审会话结论"可合并"。
- **合并即删分支**；每个 L2 合并后 `git push` main（备份 + 贡献轨迹）。

## 7. 配置规范

- 配置结构体按模块分组（gateway / store / redis / channel / meter / ...），yaml 键 kebab-case。
- 敏感项（DB 密码、加密 master key）**只从环境变量读取**，配置文件与仓库中不出现任何密钥。
- 每个配置项必须有默认值；启动时 fail-fast 校验（非法值直接退出并说明原因）。

## 8. 安全基线

- **API Key**：`sk-` + 32B 随机；库中只存 SHA-256 hash + 前 8 位前缀（索引用）；明文仅在创建响应中返回一次。
- **渠道上游 Key**：AES-256-GCM 加密存储，master key 来自环境变量，nonce 随机；解密结果仅在内存中使用，不落日志。
- **密码**：bcrypt（cost 10）。
- **B3 澄清候选**：除用户 API Key 创建成功的单次响应（含 13.4 本地创建命令的受控 stdout）外，任何响应不回显完整 Key；列表、错误、控制 API、日志与后续页面均无明文／hash。创建输出本身也不进入日志／仓库；web 页面由 html/template 自动转义防 XSS。该措辞与上一条“创建时返回一次”一致，不扩张为其他接口例外。

## 9. 工作流与角色分工

多会话协作的**自证隔离**原则：每个产出必须有第二双眼睛——实现会话的代码由评审会话验，主会话的文档决策由用户 review，任何人不得对自己的产出闭环验收。

| 角色 | 职责 | 禁止 |
|---|---|---|
| 主会话 | 文档树撰写/修正、00 契约变更、遗留事项处置决策、prompt 组织、验收独立复核 | **写实现代码（含 follow-up，再小也回实现会话）** |
| 实现会话 | 按一份 L2 施工图写代码与测试、里程碑汇报、回填 §9 验收记录 | 修改文档契约、扩大 L2 边界 |
| 评审会话 | 独立复跑验收 + 读码，输出问题清单与结论 | 修改代码与文档 |
| 用户 | 会话间转述、review 拍板、合并与 push | — |

会话协作协议：

1. **里程碑停点**：实现会话按施工图的里程碑逐段交付、逐段等确认，不得一口气冲到底。
2. **文档矛盾处理**：实现会话先在文档树内找旁证（其他 L1/L2、DDL、台账是否已有答案）——找不到才停下问，由用户转主会话；主会话修文档（带日期与理由），代码跟随文档。
3. **移交项**：代码留 `TODO(xx.y)` + 02 台账登记（§3 TODO 条目），不停留在对话里。
4. **越界处置先例**（2026-10-11）：主会话直接修复实现代码属流程违规，须经实现会话事后确认并在 §9 记录，方可视为闭环。

## 10. 本机开发环境（Windows）

- **信号语义**：无法向原生 Windows 进程发送 SIGTERM；Git Bash `kill` 对非 MSYS 进程是 TerminateProcess 硬终止。优雅关闭验证采用分层方案（自动化测关闭函数 / Ctrl+C 验 Interrupt 路径 / 容器内 SIGTERM 挂 20.1），详见 10.2 §5/§9 的完整实证。
- **e2e 脚本**：`test/e2e/` 使用 POSIX 子集（`#!/usr/bin/env bash`），在 Git Bash 运行；涉及半开连接的实验用 PowerShell（MSYS bash 对 /dev/tcp 有崩溃窗口，10.2 §9）。
- **端口偏差**：本机 3306 被原生 mysqld 占用，docker MySQL 映射宿主 **3307**（`deploy/infra/.env`，gitignored，台账 #5）——网关与测试须 `GAIGATE_MYSQL_PORT=3307`。
- **Docker Desktop** 须手动启动后再 `docker compose -f deploy/infra/docker-compose.yml up -d`。
- golangci-lint v2：测试豁免规则用 `linters.exclusions.rules`（v1 的 `issues.exclude-rules` 被静默忽略，11.1 §9.9）。
