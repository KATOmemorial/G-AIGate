## 2. 权威usage

- 非nil的Usage是已知值，0／0合法；计数非负，input+output须可表示int64。显式nil才表示缺失，不以tokens==0判断缺失。
- Finish优先取传入的最终ForwardResult.Usage；同步Observe收到的最后一个有效UsageDone／非流式response.Usage可提供相同权威值。多处同时存在必须一致，不一致返回安全计量错误，不猜一个、不相加。多次累计usage帧只替换快照，绝不逐帧求和。
- Usage／Raw当场复制／解析，不保存provider对象指针或Raw；Collector只供一个attempt串行使用，不持有ctx／Principal／Key／完整输出流。
- Finish重复同输入返回相同独立值，Finish后Observe拒绝改变结果（安全记录或无副作用忽略，不panic）；构造／Observe／Finish的坏输入不改变HTTP输出、不泄露正文。
- Observe无返回值，内部锁存解析／计数错误，Finish返回该安全错误；不得从同步回调panic或直接写HTTP错误。Finish后以不同usage／response再次调用是非法使用并报错，不能悄悄更改已冻结结果；同输入重复始终一致。

## 3. 估算范围与精度

仅最终成功而缺权威usage时使用。原“字符/4、±20%”不能作为准确token承诺：已确认口径是**确定性字符代理**，estimated=true；图片／音频不调用tokenizer或下载URL，不宣称计入供应商实际多模态token。

输入字符数：将Messages视为原始JSON对象数组，标准encoding/json解码（UseNumber）后重新编码为稳定紧凑JSON，对编码结果计UTF-8 rune；另对Extra中tools／tool_choice／response_format存在的值以同样方法各计一次。键按编码器稳定顺序，JSON空白不改变计数；Messages角色／工具／多模态结构的文本、URL或data字符串均只作为此代理的字符，不获得语义权重。忽略model／stream／stream_options／max_tokens等非上述字段；不修改原RawMessage／Extra。

输出字符数：流式解析Chunk.Raw中choices[*].delta；content字符串、tool_calls[*].function.name／arguments字符串按解码后的rune逐事件累加，元数据role／index／finish_reason不计。content为结构数组或其他非文本delta值时，计该值稳定紧凑JSON的rune，标记仍estimated；不得下载／执行工具。未知delta字段按其值稳定紧凑JSON计入一次，不存储原值。非流式对choices[*].message用同样规则处理，text completion兼容值如不在当前ChatResponse协议内不擅自新增支持。文本／工具碎片先累计字符、最后取整，不能每片ceil制造切分放大；未知结构的分片估算可能有编码开销差异，明确不承诺等价tokenizer。

input_tokens=ceil(input_chars/C)，output_tokens=ceil(output_chars/C)，分别计算；输出无字符为0。C沿meter.estimate-chars-per-token默认4，须有限、0.001..1024且可表示最多六位十进制小数。用最短十进制表示建立精确有理数，禁止逐片浮点累计／静默四舍五入。字符计数／结果／input+output越界返回错误，不截断、饱和或转uint32。

输入只在构造时处理一次，输出只保留有界计数及usage快照；单事件解析内存受既有帧上限约束，不积累完整输出。非法UTF-8／坏JSON／不合法usage返回安全错误，不打印Raw。不能更改透传请求、偷偷删未知字段或让代理消费比既有provider更多事件。

## 4. 未来接线约定

17.3在每次真实attempt创建独立Collector，stream通过原同步onChunk回调观察成功写出Chunk／UsageDone；nonstream在opener中复制必要response信息供Finish。失败／取消／写失败不对用户估算收费，即使收到过usage也不变成成功；只对最终成功attempt调用Finish构造可计费Measurement。前面的失败attempt不污染后一次。

17.1不让旧UsageSink变成同步API，不把store.UsageRecord复制一份到meter；Estimated入库仍按int8 0/1。旧uint32列宽不足问题由17.2迁移解决；本份返回provider.Usage的int64，不预先窄化。#15／#17／#24冻结消费说明见00，未独审／交付前不关闭。
