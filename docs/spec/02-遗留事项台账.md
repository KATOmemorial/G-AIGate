## 为什么需要本台账

代码 `TODO(xx.y)`、L2 文档 §9 的移交记录、00 变更流程各自接住一部分移交项，但**目标 L2 文档尚未撰写**的事项（如"留给 14.3"）此前无处安放，只能活在易失的对话里。本台账补上这个落点。

## 规则

1. **谁登记**：任何会话（实现/评审/主会话）发现"不属当前 L2 处置、需未来某个模块/文档接手"的事项，追加一行——不删除、不改动他人行。
2. **同步标记**：能在代码处留 `TODO(xx.y)` 的必须留（01 §3）；本台账登记编号在注释中引用（如 `台账#3`）。
3. **谁消费**：主会话撰写某 L2 文档前，**必查本台账**，将归属该模块的 open 条目折入文档需求（§2 目标或 §7 风险），状态改为"已折入 xx.y"。
4. **何时关闭**：接手 L2 验收合并后，状态改"已关闭"，轨迹列记录处置 commit/文档节。
5. 与 00 §10 的分工：**契约变更**（接口/表结构/Redis key）登记 00 §11；其余移交项（实现缺口、验证挂起、环境问题）登记本台账。
