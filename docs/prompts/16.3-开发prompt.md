## 四、三key、时间、状态及原子性

冻结key为`gaigate:breaker:{channelID}` HASH、`gaigate:breaker:events:{channelID}` ZSET、`gaigate:breaker:pending:{channelID}` ZSET，同一hash tag；三key显式作为Lua KEYS，不动态拼跨slot key。channelID规范化十进制不经Lua double重编码，epoch／token为不透明唯一字符串。

HASH保存schema／policy指纹、三态、epoch、open_until_ms、probe_token／probe_until_ms且不TTL。events保存完整有效完成窗口，token＋结果标记保证同毫秒多事件不覆盖；不按最近N条截断。pending区分epoch／token／许可类别与截止，每channel最多4096个尚有效在途许可，closed亦登记，不抢占已有许可。

生产权威时间为Lua Redis TIME毫秒；窗口(now-window,now]，Complete实际处理时刻入样本，now>=until到期。时间加法及failure*1000000与n*thresholdPPM精确且有上界检查，超Lua安全整数或乘法安全范围返回error，不近似比较或先写后发现溢出。

Inspect只读：全key缺失返回closed／Eligible=true，存在状态需校验；closed有容量、open到期、probe过期可Eligible，活跃probe不可。不能初始化、清理到期pending／事件、刷新TTL、转态或占许可；重复Inspect不能消耗半开机会。

Acquire一次原子脚本校验／清理到期许可、判资格、登记token；冷启动初始化closed新epoch，open到期或probe过期才取得一个新half-open。未到期open拒绝不能延长冷却，满容量拒绝不能丢旧许可。

Complete仅消费本permit对应的有效pending一次。closed success／failure分别入样本，n>=MinSamples且精确失败率>=阈值才open并换epoch；neutral只释放、不进分母。有效probe success清窗closed新epoch，failure重开冷却，neutral回到open_until=now的可再领取open并换epoch，不宣称恢复。

重复、过期、旧epoch结果无当前窗口／状态变化，不释放别的token／新probe；旧closed晚到成功不能关闭open，旧probe晚到不能覆盖新probe。正常过期pending自身可清理，不把它混写成所有失效Complete必须全key逐字零写。

错误类型、孤儿events／pending、缺字段／坏枚举／非法数值／不匹配指纹等fail closed；未过期probe须有对应pending。所有输入／状态／新计算结果检查先于任何写入，Lua运行错误不会自动回滚，需机制证据证明坏状态不产生部分裁剪／计数／转态。保留未知HASH扩展字段，不触健康／配额key。

events TTL至少覆盖最后完成起完整Window；pending TTL不早于全部有效lease最大截止，短lease后续操作不能提前删长lease或活跃probe。HASH长期保留；空闲窗口可自然过期。指纹沿冻结schema、Window、MinSamples、阈值PPM、OpenDuration及4096口径；多副本不匹配报错，不自动重置。变更策略须协调停流并显式清理三key，不能加裸重置工具或只删HASH。

一次Acquire公开调用中生成的token跨go-redis透明重试保持相同；重复执行同一有效token返回原许可／截止，不再占位或续lease。最终返回error则调用方不出站，遗留许可至多原lease。Complete丢回包重试同permit幂等；NOSCRIPT回退沿既有Script机制，不丢样本或重开预算。不要用本地mutex代替跨副本原子性。
