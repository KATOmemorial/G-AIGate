## 三、实现时必须落实的契约

### 1. 请求、客户端与 HTTP

- messages 保留为原始 JSON 对象列表，其余顶层字段由 Extra 保留；不收窄 content 为 string，不丢 tools／多模态／未知字段。模型按 Endpoint.Model 重写；流式合并 stream_options.include_usage=true，并保留其他选项，缺失／null 时新建。非流式不注入，输入对象及嵌套 RawMessage 只读，并发复用不受污染。
- BaseURL 支持服务根、/v1 根、已有路径前缀和尾斜杠，正确组成 chat/completions 路径，不能 /v1/v1；仅 http／https、有 host，拒绝 userinfo／query／fragment。非法输入在网络前拒绝。
- 仅使用 Endpoint 的上游 APIKey，不透传客户端 Authorization／Cookie／任意 X-*／X-Mock-Scenario。只认 HTTP 200 成功，正确校验流／非流 Content-Type（允许参数）。不自动重试、不跟随重定向泄露凭据。
- New 拒绝 nil client／非正 streamBuffer；调用方 client／共享 Transport 不原地修改。client.Timeout=0，与调用方 context 配合；具体校验或复制策略按冻结文档自行合理实现并验证，不新增一套全局配置。容量参数沿 ProxyConfig.StreamBuffer（默认64）注入，本层不直接读取配置或环境。
- ChatStream 得到合法响应头后返回 Stream，首事件可稍后到达。连接、响应头、body 读和阻塞入队必须遵循传入 context；本层不另设或重启 TTFB。未来 proxy 在 opener 调用前建立完整预算，本轮只实现取消与生命周期前提。

### 2. 非流式与分类错误

- 完整响应为单个 JSON 对象，不能空体／尾随 JSON／无限读取，正文上限10MiB；Body 保留原字节。usage 缺失／null 是 nil，存在时 prompt_tokens／completion_tokens 为非负 int64 整数；零值有效，类型错误／溢出为协议错误。ChatResponse.Usage 和方法返回 Usage 值一致。
- 非200／网络错误按冻结 UpstreamError 字段与 Retryable 规则分类；errors.As、Unwrap 保留原因。context 取消／超时可由上层优先判定，不用字符串判断或回显完整 URL／错误体。
- 错误体最多探读1025字节、保留前1024字节并设置 BodyTruncated；不日志打印。完整 JSON 任意字符串若含 Endpoint.APIKey，丢弃 Body；截断／不安全错误体不能成为未来客户端透传依据。Error() 不含 Body／URL 凭据。

### 3. SSE 与资源 owner

- 事件严格区分 **Chunk／UsageDone／Done／Error**。独立 usage 帧要求 choices=[]；非空 usage 与内容混合属于本冻结子集的协议错误，不擅自扩张协议。正常缺 usage 可成功，缺 Done 不可成功。
- [DONE] 必须产生一次 Done 事件、Raw=[DONE]，随后停止读取并释放 body／关闭 channel。未见 Done 的正常 HTTP EOF、真实截断、读错、坏 JSON、非法 usage 或超限帧，产生一个带非 nil Err 的 Error，并可 errors.Is 匹配 provider.ErrStreamInterrupted；不得伪造 Done。
- 支持 LF／CRLF、空行分 event、多行 data；仅移除冒号后的一个可选空格，不 TrimSpace 正文。Raw 保留 data 内容，注释／event／id／retry 忽略，无 data 的 event 不作为可转发载荷。
- 单 event 累计输入上限1MiB，含非 data 行；验证恰好上限／超限，不能暗用 Scanner 默认64KiB，也不能为“无限注释”无界累积。
- 固定容量 channel 满时停止继续解析，不丢帧、不无界缓存；Raw 事件独占，不能被下一次读取复用缓冲覆盖。唯一 worker 负责关闭 Events。
- Close 幂等，取消上游 HTTP、关闭 body，**等待所属 worker 退出**；并发 Close、空读、满 channel 时都可退出，不自等待。正常 Done／异常退出也释放 body。取消时不要求最后一个 Error 一定投递，调用方据 context 分类。使用符合01规范的生命周期管理，不裸启动无人回收的请求 goroutine。

具体字段、签名、错误和边界以冻结正文为准。若发现矛盾，先查00／L1／L2／现有实现和台账；确实无裁定再报告最小冲突、触发条件和建议，由用户转主会话。不自行改冻结契约，不因一般实现取舍反复停工。
